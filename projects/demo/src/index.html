ngx-json-render

Generative UI for Angular: a renderer for json-render, Vercel's format for model-generated UI. Give a model a catalog of your components, stream back a JSON spec, and render it as real Angular components with signals. No innerHTML, no eval; the same spec the React, Vue, Svelte and Solid renderers consume.

npm install ngx-json-render @json-render/core zod
